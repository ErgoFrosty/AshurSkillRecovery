# Ashur Skill Recovery

Независимый дневник восстановления заработанного прогресса для Project
Zomboid Build 42.20.

Этот репозиторий предназначен для разработки. Тестовая сборка использует ID
`AshurSkillRecoveryDev`, будущая публичная версия — `AshurSkillRecovery`.

## Главное правило

Записывается только прогресс, заработанный после создания персонажа. Точный XP,
который выдан профессией и стартовыми чертами, сохраняется как базовый и никогда
не переносится.

```text
заработано = max(0, текущийXP - стартовыйXP источника)
цель       = стартовыйXP нового персонажа + заработано * процент
выдать     = max(0, цель - текущийXP нового персонажа)
```

Повторное чтение в одной жизни не может повторно выдать тот же XP. После смерти
следующий персонаж снова может восстановиться из того же дневника.

## Текущий объём разработки

- Только Build 42.20.
- SP, hosted MP и dedicated server.
- Точный заработанный XP ванильных и обнаруженных модовых навыков.
- Опциональное восстановление изученных рецептов.
- Опциональные Фитнес и Сила по тому же правилу стартовой базы.
- Расчёты и проверки выполняются сервером; клиент не передаёт значения XP.
- Нет внешних ledger-файлов и обязательных зависимостей.

Убийства и произвольный `modData` других модов намеренно исключены из первой
версии.

### Какие навыки записываются

Мод не использует хрупкий жёстко заданный список. Он перебирает все навыки,
которые зарегистрированы запущенной игрой и принадлежат реальной категории.
Сюда входят:

- Фитнес и Сила (по умолчанию включены, отключаются sandbox-настройкой);
- Бег и остальные физические навыки/навыки ловкости;
- навыки оружия ближнего боя и Обслуживание;
- Меткость и Перезарядка;
- ремесленные, фермерские навыки и навыки выживания;
- совместимые навыки, зарегистрированные другими модами.

Для каждого из них записывается только точный XP сверх стартовой базы этого
персонажа.

### Какие рецепты записываются

Рецепты, известные при создании персонажа, считаются стартовой базой и не
переносятся. Любой рецепт, который позже появился в списке известных рецептов,
записывается — в том числе полученный через действие **«Изучить»** у предмета.
При восстановлении добавляются только ещё неизвестные рецепты. Запись рецептов
включена по умолчанию и отключается sandbox-настройкой.

## Локальная тестовая сборка

```powershell
./build.ps1 -LocalTest
```

Скопируйте `dist/AshurSkillRecoveryDev` в каталог модов Project Zomboid.

Архитектура описана в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), обязательные
сценарии проверки — в [docs/TEST-MATRIX.md](docs/TEST-MATRIX.md).
